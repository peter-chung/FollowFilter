# FollowFilter

A simple and lightweight Chrome extension that lets you hide Twitch streamers you follow by category.

## Features

- Hide any category from your Following page and filtered streamers are automatically removed from view
- Sidebar filtering hides categories from the Following panel on the left as well
- One-click blocking: hover any category name and click the eye icon to hide it instantly
- Manage your following list by adding or removing categories from the popup at any time
- On/Off toggle to disable all filtering without losing your category list
- Synced across devices via Chrome sync storage

## Installation

1. Click the green **Code** button on this page and select **Download ZIP**
2. Unzip the downloaded file
3. Open the unzipped folder -- GitHub adds an extra outer folder (e.g. `FollowFilter-main`), so open that and locate the inner folder containing the `content`, `icons`, and `popup` folders
4. Go to `chrome://extensions/` in Chrome and enable **Developer mode** (top right toggle)
5. Click **Load unpacked** and select that inner folder

## Usage

1. Navigate to [twitch.tv](https://www.twitch.tv) and open your Following page
2. Hover over any category name and click the icon to hide it
3. Or open the extension popup to manually add or remove categories
